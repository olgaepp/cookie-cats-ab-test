# cookie-cats-ab-test
Product analytics project analyzing a mobile game A/B test using Python, hypothesis testing, and behavioral segmentation.
# Cookie Cats A/B Test Analysis

## Project Overview
This project analyzes an A/B experiment from the mobile game Cookie Cats to determine whether moving the first progression gate affects player retention.

## Dataset
The dataset is sourced from Kaggle and it contains gameplay information for over 90,000 players, including:
- number of game rounds
- day 1 retention
- day 7 retention
- experiment group

## Methods
The analysis includes:
- exploratory data analysis
- outlier inspection
- hypothesis testing
- player behavior segmentation
- logistic regression

## Tools
Python, Pandas, NumPy, SciPy, Seaborn, Matplotlib, Scikit-learn
